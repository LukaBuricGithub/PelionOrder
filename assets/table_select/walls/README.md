# Odabir stola — wall frame (nine-slice)

The room walls are a fixed bezel; the table grid scrolls inside. Deliver EITHER the 8 nine-slice
pieces below, OR the single-file fallback. All SVG, flat, transparent center/background.

## Option A — nine-slice (preferred): 8 files
Corners (fixed, ~64×64 dp, all ornament lives here):
- `corner_tl.svg`
- `corner_tr.svg`
- `corner_bl.svg`
- `corner_br.svg`

Edges (plain straight wall, tile seamlessly; thickness ~22 dp = corner arm thickness):
- `edge_top.svg`     (tiles left↔right)
- `edge_bottom.svg`  (tiles left↔right)
- `edge_left.svg`    (tiles up↕down)
- `edge_right.svg`   (tiles up↕down)

## Option B — fallback: 1 file
- `frame_full.svg` — a uniform-thickness rounded border (detail only in corners), stretched by the app.

Use one option or the other, not both.
